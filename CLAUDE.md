# ai-motion-to-sprites - rules for every session

- **Branch, commit, push, pull request, merge:** read [.claude/skills/pull-request/SKILL.md](.claude/skills/pull-request/SKILL.md)
  first. In short: `<type>/<area>-<short>` branch from `develop`, Conventional Commits in English, PR to `develop`
  with the template, merge on green CI. No co-author lines and no tool credits anywhere.
- **Pipeline, rig, motion, audit:** [.claude/skills/ai-motion/SKILL.md](.claude/skills/ai-motion/SKILL.md).
- **Commercial use only:** a dependency, checkpoint or dataset enters after its license is in
  [LICENSES.md](LICENSES.md) and both license scans pass. Weights and data are checked separately from code.
- **English** in code, comments, docs, commits and PRs.
- **Never commit** characters, models, renders, motion files, tokens or anything under `local/`.
